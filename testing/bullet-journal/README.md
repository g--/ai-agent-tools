# Bullet Journal Tests

This directory tests whether `bullet-journal` records concise, linked journal entries that are useful in a Logseq or block-outliner workflow. Compare a baseline with the focused-skill version, then review the pair against each case's intended reader, constraints, and completion criteria.

Use the same blinded comparison process as `testing/writing-prose/`. Read `skills/bullet-journal/SKILL.md` before changing these fixtures. When the skill gains an observable quality goal, add or revise a case here and check whether `skills/review-prose/rubric.md` needs a corresponding reader-outcome criterion.
