# Case: revise a dependency-update announcement

## Test purpose

Test whether the skill removes decorative emphasis without making a required action, deadline, rationale, or support route harder to find.

## Intended artifact

A short internal announcement for application teams.

## Task

Revise the draft for its intended readers. Preserve supported facts and intended meaning. Do not introduce facts not present in the source material.

## Source material

All application teams must update to dependency version 4.3 by Friday. Version 4.2 mishandles signed payloads from the new gateway. The platform team will answer questions in `#platform-help`. The security review did not identify exploitation in production.

## Draft to revise

# **Important dependency update**

**All application teams** must **immediately** update to **version 4.3** by **Friday**.

The **reason** is that **version 4.2** mishandles **signed payloads** from the **new gateway**. **Contact** the **platform team** in **#platform-help** if you have questions.

## Evaluation criteria

The revision makes the required action, deadline, reason, and support route easy to find without applying bold or headings as generic emphasis. It preserves the fact that no production exploitation was identified without overstating that fact.
