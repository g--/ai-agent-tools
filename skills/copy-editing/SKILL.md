# Copy Editing

Preserve the author's intent. Improve the draft's reader path, clarity, accuracy, earned brevity, and mechanics without inventing facts or silently changing a material claim, decision, scope, or tone.

1. Identify the draft's purpose, audience, claims, constraints, and requested level of intervention. Ask a focused question when an unresolved ambiguity would require changing meaning.
2. Edit in place where possible. Make the smallest change that removes reader friction. Restructure only when the existing order prevents comprehension.
3. Make identifiers supplementary: retain ticket links and references, but add or preserve the explanation readers need without opening them.
4. Make uncertainty visible. Keep placeholders, assumptions, and qualifications that affect the meaning.
5. Read [`../review-prose/rubric.md`](../review-prose/rubric.md) before finalizing. Apply its outcomes to the revised draft; do not copy its review report unless the user requested one.

## Deliverable

Return the edited draft. Briefly list only consequential changes, unresolved ambiguities, or factual assumptions. Preserve the original format unless a format change materially improves reader comprehension.

## Maintenance

When this skill gains a new quality goal, check [`../review-prose/rubric.md`](../review-prose/rubric.md). Update the rubric if the goal is observable in a finished draft; otherwise document why no rubric change is needed.
